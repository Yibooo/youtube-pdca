# 動画を作る手順と注意点

1本作るたびにこのファイルを見ながら進める。作業中に気づいたことは、最後の「更新履歴」に書き足し、該当する手順も直す。

## 守ること（毎回）

- **株価に関わる数字を扱わない。** 株価、時価総額、PER、PBR、配当利回り、目標株価は出さない。
- **株価の動きを分析しない。** 「この決算で株価が上がった・下がった」の話はしない。売買の推奨もしない。
- **配当も扱わない。**
- **IR 資料から読み取れることと、今後の戦略の解説に絞る。**
- **事実と会社の説明を分ける。** 数字は事実として言う。理由や見通しは「会社は〜と説明しています」の形で言う。自分の推測を入れるときは「〜と考えられます」と明示する。
- **数字は一次資料から取る。** ニュース記事やまとめサイトの数字は使わない。
- **スライドは、作る前に必ずその会社の規約を確認する**（手順2）。

## 手順

### 1. 会社と決算を決める

- Phase 1 は通期決算だけ。
- 会社の IR ニュース一覧で、通期決算の公表日と資料をそろえる。
- `episodes/epNN_<会社>_<決算期>/` を作る。

### 2. 規約を確認する（必須）

1. 会社のサイトのフッターから、次のページを探して読む。
   - 免責事項
   - サイトのご利用条件（利用規約）
   - 著作権
   - リンクポリシー
2. 著作物の使用について書かれた文を、そのまま `PLAN.md` の「規約の確認」に写す。確認した日と URL も書く。
3. 判定する。

| 規約の書き方 | 判定 |
|---|---|
| 著作物の使用について書いていない | スライドを使う |
| 「著作権法で認められた範囲を超えて許諾なく使えない」のように、法律の範囲内の利用を認めている | スライドを使う |
| 引用・転載・動画での使用をはっきり禁止している | スライドは使わず、数字から自分で図を作る |
| 写真などを自由に使ってよいと書いている（フォトライブラリーなど） | その画像は使ってよい。対象の範囲を `PLAN.md` に書く |

- スライドを使う場合も、引用の形を守る（下の「スライドの見せ方」）。
- 企業ロゴは使わない。社名は文字で書く。

### 3. 資料を集める

| 優先 | 資料 | 取るもの |
|---|---|---|
| 1 | 決算短信 | 損益計算書、セグメント情報、販管費の内訳 |
| 2 | 決算説明会資料、決算サマリー | 増減の理由、地域別の数字、来期の見通し |
| 3 | 有価証券報告書 | 事業の内容、リスク、従業員数、平均年収、平均勤続年数 |
| 4 | 経営者のプレゼン、統合報告書、中期経営計画 | 戦略 |

- 有価証券報告書は決算発表から1〜3か月遅れて出る。出ていなければ `PLAN.md` にそう書き、出たら追加する。
- 資料の URL と公表日を `PLAN.md` の「使った資料」に書く。

### 4. 数字を入れて検算する

- 決算短信の数字（百万円）を `data.json` に書く。表示は会社の資料に合わせて億未満を切り捨てる。
- 次の検算を必ずする。
  - 売上収益 − 売上原価 ＝ 売上総利益
  - 売上総利益 − 販管費 ＝ 営業利益（IFRS の会社は、会社が使う指標。ファーストリテイリングは「事業利益」）
  - セグメントの売上の合計 ＝ 連結の売上（「その他」「調整額」も含める）
  - 流れ図の各段で、入る帯の合計と出る帯の合計が同じ
- 日本基準と IFRS で項目が違う。日本基準は「営業外収益・費用」「経常利益」「特別損益」がある。IFRS は「その他の収益・費用」「金融収益・費用」で、経常利益がない。

### 5. 分析して骨子を作る

- 伝えるポイントを5つ以内に絞る。
  - 何で稼いだか
  - どこが伸びたか
  - 利益率はなぜ変わったか
  - 弱いところ
  - 来期の見通しと戦略
- 3つの対象（ビジネスマン、転職・就活、個人投資家）すべてに向けて、それぞれの見どころを1つずつ入れる。
- 骨子は `PLAN.md` に書く。長さは10〜12分を目安にする。

### 6. 図とサムネを作る

```bash
python scripts/sankey.py episodes/<id>/data.json episodes/<id>/sankey.png
python scripts/sankey.py episodes/<id>/data.json episodes/<id>/thumbnail.png --thumb
```

- 流れ図は、説明したい部分を1か所だけ強調する（`thumbnail.highlight`）。
- サムネの一言は、図の強調部分と同じことを言う。入れる数字は資料で確かめられるものにする。
- 他の書籍・サービスのデザインやキャラクターを流用しない。

### 7. スライドの見せ方

- 枚数は決めない。ただし1枚ごとに必ず自分の解説を付け、解説が主になるようにする。「今後の戦略」のように会社の説明そのものが中身になるパートは、スライドを多めに使ってよい（#1 は12枚）。
- 枠で囲み、自作の図と区別する。
- 画面下に「出典：〇〇株式会社『資料名』（公表日）」を出す。
- 文字や数字を書き換えない。強調の印は上に重ねる。
- 映している間は、そのスライドを自分の言葉で読み解く。読み上げるだけにしない。

### 8. 台本を書く

- 冒頭30秒で一番強い事実を言う（例：「増えた売上の約9割が海外」）。
- 専門用語は初めて出たときに一言で説明する。
- 数字と固有名詞の読みを、音声エンジンの読み（`audio_query` の kana）で確かめる。下の「読み間違いの一覧」に載っている語は特に見る。
- 動画の最後に注意書きを入れる：「この動画は IR 資料をもとにした解説で、投資を勧めるものではありません」。注意書きは最後の1回だけにし、冒頭で繰り返さない。
- 同じことを2回言わない。冒頭で言ったことを、すぐ後でもう一度言わない。
- 対象外の話題を入れない。配当は株価や投資判断に近い話題なので、Phase 1 では扱わない。

#### 読み間違いの一覧（見つけたら追記する）

| 書き方 | 誤った読み | 正しい読み | 直し方 |
|---|---|---|---|
| 〜している方、投資家の方 | ほう | かた | そのセリフだけ `r` で「かた」と書く（「方」は「ほう」と読む場面もあるので、一括では置き換えない） |
| 税引前利益 | ぜいびき**ぜん**りえき | ぜいびき**まえ**りえき | `readings` に `"税引前": "ぜいびきまえ"` |
| 中間層 | ちゅう**げん**そう | ちゅう**かん**そう | `readings` に `"中間層": "ちゅうかんそう"` |
| IR | （英字のまま） | アイアール | `readings` に `"IR": "アイアール"` |
| スクラップ＆ビルド | （記号を読まない） | スクラップアンドビルド | `readings` に追加 |

正しく読めた語（確認済み）：当期利益（とうき）、地代家賃（じだいやちん）、減価償却費、売上総利益（そうりえき）、非支配持分、第4四半期、欧米、旗艦店、GU（「ジーユー」とカタカナで書く）。

### 9. 動画を作る

1. 資料の PDF を `episodes/<id>/sources/` に置く（Git には入れない）。
2. 台本と画面を `episodes/<id>/spec.json` に書く。
   - `scenes`：章（`chapter`）ごとにセリフ（`lines`）を並べる。章がそのまま YouTube のチャプターになる。
   - セリフの `t` が字幕と読み上げの文。画面は `v` で指定し、次に `v` が出るまで同じ画面を出す。
   - 画面の種類：`title`（大きな文字）、`points`（箇条書き）、`sankey`（流れ図。`upto` で途中の列まで、`highlight` で強調）、`bars`（棒グラフ）、`table`（表）、`cards`（カード）、`slide`（スライドの引用。PDF とページを指定）。
   - 読みを変えたい語は `readings` に書く（例：`"IR": "アイアール"`）。
3. VOICEVOX を起動して動画を作る。

```bash
~/voicevox/macos-arm64/run --host 127.0.0.1 --port 50021
python scripts/make_video.py episodes/<id>/spec.json
```

4. `build/` にできたものを確認する。
   - `video.mp4`：動画
   - `thumbnail.png`：サムネ
   - `chapters.txt`：チャプター
   - `kana.txt`：全セリフの読み。数字と固有名詞の読みを確認する
   - `frames/`：全画面。重なりや切れがないか確認する

- 声は当面 VOICEVOX の「No.7 アナウンス」（速さ 1.1）。参考動画のような声（ElevenLabs など）に変えるかは検証中。
- 説明会資料の PDF は「スライド＋話す原稿」の縦長ページなので、`slide` はスライドの外枠で自動的に切り出す。外枠のない資料は切り出しを確認する。

### 10. 公開前の確認

- [ ] 画面と台本の数字が、決算短信と一致している
- [ ] 株価に関わる数字や、株価の動きの話が入っていない
- [ ] 引用したスライドに出典が出ている
- [ ] 規約の確認結果が `PLAN.md` にある
- [ ] 概要欄に、使った資料の名前と URL、AI 利用の表示、注意書きがある

### 11. アップロード

- 非公開でアップロードし、公開はチャンネル所有者が YouTube Studio で行う。

## 概要欄のひな形

```
<会社名>の<決算期>の決算を、IR資料から読み解きます。

━━━━━━━━━━━━━━━━
⏰ チャプター
{chapters}
━━━━━━━━━━━━━━━━

▼使った資料（<会社名> IRサイト）
・<資料名>（<公表日>）<URL>

この動画はIR資料をもとにした解説で、投資を勧めるものではありません。
この動画はAIを使って制作しています（台本の作成支援・図の自動作成・音声合成）。
```

## 画面づくりの注意

- カードが3枚以下のときは、横いっぱいの段を縦に並べる。2列にすると空白が残って不自然になる。
- 箇条書きが5項目以上のときは、行の間隔を詰めて画面に収める。
