# IR・決算解説Channel：方針

企業が公開している IR 資料（決算短信、決算説明会資料、有価証券報告書など）を読み解き、やさしく解説するチャンネル。

**動画を作るときは、毎回 [WORKFLOW.md](./WORKFLOW.md)（手順と注意点）を見ながら進める。**

## 1. チャンネルの概要

| 項目 | 内容 |
|---|---|
| テーマ | 「その会社は、何で稼いで、どこにお金を使い、いくら残ったか」を1本で分かるようにする |
| 対象 | ① ビジネスマン ② 転職・就活を考える人 ③ 個人投資家。どれかに絞らず、全員に向けて作る |
| 入口 | 「<企業名> IR」「<企業名> 決算」で検索する人 |
| 差別化 | 売上から利益までの流れ図（サンキー図）を毎回自分で作り、サムネと動画の軸にする |

### 対象ごとの見どころ

| 対象 | 知りたいこと | 動画で扱う資料 |
|---|---|---|
| ビジネスマン | 強い会社の稼ぎ方、戦略 | 決算説明会資料、経営者のプレゼン |
| 転職・就活 | 会社の伸び方、どの事業が伸びているか、働く環境 | セグメント情報、有価証券報告書（従業員・平均年収・人的資本） |
| 個人投資家 | 増収増益の理由、来期の見通し、リスク | 決算短信、業績予想、配当 |

## 2. 動画の方針

- **Phase 1 は通期決算だけを扱う。** 四半期・半期は扱わない。
- 1社1本。決算短信の数字を土台に、決算説明会資料と有価証券報告書で理由を補う。
- **数字は必ず一次資料から取る。** ニュース記事や他のまとめサイトの数字は使わない。
- **株価は扱わない。** 株価に関わる数字（株価、時価総額、PER、配当利回りなど）を出さない。「この決算で株価が上がった・下がった」の分析もしない。
- **IR 資料から読み取れることと、今後の戦略の解説に絞る。** 個人投資家にも、業績と戦略の読み解きとして見てもらう。
- 長さは10分前後を目安にする。囲碁チャンネルの振り返りで、1本が短いと再生時間が積み上がらないことが分かったため（[../IGO Channel/Review.md](../IGO%20Channel/Review.md)）。

### 使う資料（優先順）

| 優先 | 資料 | 使い道 |
|---|---|---|
| 1 | 決算短信 | 損益計算書、セグメント別の売上と利益。流れ図の数字はすべてここから取る |
| 2 | 決算説明会資料・決算サマリー | 増減の理由、地域別の数字、来期の見通し |
| 3 | 有価証券報告書 | 事業の内容、リスク、従業員数・平均年収・平均勤続年数（転職・就活向け） |
| 4 | 経営者のプレゼン資料、統合報告書 | 戦略、ビジョン |

## 3. IR 資料を動画で使ってよいか

**決定（2026-11-14）：** 動画を作る前に、毎回その会社の規約を確認する。はっきり禁止されていなければスライドを使う（引用の形で）。禁止されていれば、数字から自分で図を作る。手順は [WORKFLOW.md](./WORKFLOW.md) の手順2。

> 法律の専門家の判断ではなく、資料と規約を読んだ範囲の整理である。迷う場合は弁護士か、各社の IR 窓口に確認する。

### 結論

| 使い方 | 判断 | 理由 |
|---|---|---|
| 決算の数字から自分で図を作る（流れ図、グラフ） | ◎ 使える | 数字は事実で、著作物ではない。出典は書く |
| スライドを1枚ずつ映して、自分の解説を付ける | ○ 条件付きで使える | 著作権法32条の「引用」の条件を守る（下記） |
| スライドを何枚も続けて映し、読み上げるだけ | × 使わない | 解説が主にならず、引用にならない |
| スライドや企業ロゴをサムネに使う | × 使わない | サムネは宣伝の画像で、引用の「主従関係」が成り立ちにくい。ロゴは商標でもある |
| 会社がフォトライブラリーで公開している画像 | ◎ 使える（ファーストリテイリングの場合） | 同社の免責事項に「フォトライブラリーに掲載されている画像は、ご自由にご利用いただけます」とある |

### スライドを引用するときの条件

1. **区別する：** スライドは枠で囲み、自分の図と見分けがつくようにする。
2. **解説が主：** スライドを映している間は、そのスライドの読み解きを話す。動画の大半は自作の図で構成する。
3. **必要な分だけ：** 枚数は決めないが、1枚ごとに必ず解説を付ける。各スライドの表示は解説に必要な時間だけにする。
4. **改変しない：** 切り抜きや拡大はよいが、数字や文字を書き換えない。強調の印は、スライドの外側か上に重ねる形で付ける。
5. **出所を書く：** 画面に「出典：〇〇株式会社『資料名』（公表日）」を出す。概要欄にも資料名と URL を書く。

ファーストリテイリングのサイトの「免責事項」には、「個人の私的使用、その他著作権法上認められている範囲を超えて、著作権者の許諾なしに、これらの著作物を使用（複製、改変、配布等含む）することはできません」とある。引用はこの「著作権法上認められている範囲」に当たる。各社の規約は会社ごとに確認する。

### サムネの図について

- 参考にした画像（他社の書籍・サービスのサンキー図）は、デザインやキャラクターを流用しない。配色、レイアウト、フォントは自分で決める。
- サンキー図という形式自体は一般的な図法で、数字も事実なので、自分で描けば問題ない。

## 4. サムネ

**売上→費用→利益の流れ図 ＋ キャッチーな一言** を基本にする。

| 要素 | ルール |
|---|---|
| 図 | 決算短信の数字から `scripts/sankey.py` で描く。説明したい部分（伸びた事業など）を1か所だけ色で強調する |
| 一言 | 3行まで。図の強調部分と同じことを言う。例：「海外が6割を稼ぐ理由」「売上減は構造的？」 |
| 社名 | 上に小さく出す。ロゴは使わない |
| 数字の裏付け | 一言に入れる数字は、必ず資料で確かめられるものにする |

## 5. 制作の流れ

1. IR ニュースから通期決算の公表日と資料を集める。
2. 決算短信の損益計算書とセグメント情報を `episodes/<id>/data.json` に書く。
3. `scripts/sankey.py` で流れ図（1920×1080）とサムネ（1280×720）を描く。
4. 決算説明会資料・サマリーから増減の理由を拾い、`episodes/<id>/PLAN.md` に骨子を書く。
5. 台本・動画を作る（未着手。囲碁チャンネルの VOICEVOX と動画生成の仕組みを流用する予定）。

```bash
python scripts/sankey.py episodes/ep01_fastretailing_fy2026/data.json episodes/ep01_fastretailing_fy2026/sankey.png
```
