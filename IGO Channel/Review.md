# 振り返り（2026-11-14）

定石 #1〜#50、Shorts 10本、詰碁 #1 を出した時点の振り返り。

## 良かった点

- 初めて定期的な視聴者がついた。
- 視聴時間と登録者も増えた。

## 課題

### 1. 1本あたりの動画が短い

当初の想定は1本8〜12分（[STRATEGY.md](./STRATEGY.md)）だったが、実際はほとんど1分台で終わっている。

| 種類 | 本数 | 長さ |
|---|---|---|
| 定石 | 50 | 約1分（55秒〜2分32秒）。2分を超えたのは #1・#2・#14・#41 の4本だけ |
| 詰碁 | 1 | 1分6秒 |
| Shorts | 10 | 35〜55秒 |

- 1本で扱うのは「1つの定石の間違い1〜2手」か「詰碁1問」なので、話すことがすぐ尽きる。
- 収益化の条件は総再生時間なので、短い動画では時間が積み上がりにくい。

### 2. 定石・詰碁の手筋の正しさを保つのが難しい

動画を長くしようとして変化や解説を増やすほど、間違いが入りやすくなる。

- **用語の誤り：** 出す前の見直しで、石の形の呼び方の誤りを何度も見つけた。例：#49 の「肩ツキ」は正しくは「外からのツケ」、#47 の「トビ」は「コスミ」、#46 の「サガリ」は「コスミ」。
- **確認できる範囲が狭い：** 手順は複数のソースと KataGo で照合しているが、照合できるのは基本形と主な間違いの手までである。長くするために変化を足すと、照合できない手が増える。
- **KataGo の評価をそのまま使えない：** 詰碁では、外に抜ける手をふさがないと、KataGo が別の場所を打つ評価を出した。周りに石を足して形を閉じる必要がある。
- **詰碁の正解：** 60問の正解は出典の解答図を写したもので、KataGo で確かめたのは #1 の1問だけである。

## 次に試すこと

- **長尺のまとめ動画を増やす：** 確認済みの回を10問ずつ並べた長尺を作る。手順を新しく足さないので、正しさを保ったまま長くできる。
- **確認できる範囲で長くする：** 変化を足すのは、ソースと KataGo の両方で確かめられた手順だけにする。
- **数字で判断する：** YouTube Analytics の API を有効にして、視聴維持率と動画の長さの関係を見る。
