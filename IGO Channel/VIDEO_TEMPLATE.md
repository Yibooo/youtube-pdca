# 動画テンプレート（全エピソード共通）

1本の動画は「問題 → 解説 → 正解 → **不正解の手順と損失** → まとめ」で作る。
台本は `videos/<ep>/spec.json`、生成は `scripts/make_video.py`、アップロードは `scripts/upload.py`。

## 構成（必須）

| # | パート | 内容 | 必須 |
|---|---|---|---|
| 1 | 問題（冒頭15秒） | 迷いやすい局面を見せ、候補手を A / B で示して「どちらが正解？」と問う | ✅ |
| 2 | 定石の紹介 | 今回の定石の1手目と、その手の狙い | ✅ |
| 3 | 白（相手）の代表的な応手 | 候補を A / B / C で示す | ✅ |
| 4 | 正解の手順 | 1手ずつ石を置き、各手の意味を言い切る。一段落まで進める | ✅ |
| 5 | **不正解の手順** | **不正解の手を打った後、相手の反撃を手順で進めて見せる**（「危険です」で終わらせない） | ✅ |
| 6 | **不正解の損失** | **正解図と比べて何を失ったか**（地・厚み・石の働き）を説明し、「黒の損です」と言い切る。**何目の損かは言わない**（KataGo の目数は検証表に記録するだけ） | ✅ |
| 7 | まとめ | 覚えるポイントを箇条書き2〜3個 | ✅ |
| 8 | 次回予告 | プレイリスト内の次の定石 | ✅ |

不正解の手順（5）は、定石DB（OGS の MISTAKE / TRICK ノードの続き）、解説サイトの失敗図、KataGo の読み筋から探す。
どうしても見つからない場合だけ、不正解の手を✕で示して理由を説明する形にしてよい（その場合も損失の説明は入れる）。

## タイトルのルール

- 形式：`【囲碁定石 <シリーズ名> #<番号>】<キャッチーな一文>`（シリーズ表記を**先頭**に置く）
  - 例：`【囲碁定石 星・小ケイマかかり #2】その5手目のハネは危険！星の一間低バサミと三々入り`

## 台本のルール

- **プロの立場で言い切る。**「資料によると」「複数のソースで」など出典に触れる言い方は、動画でも概要欄でも使わない。出典は GitHub の検証表（`joseki/`・`sources/`）に残す。
- 小さい変化（手順の入れ替えや別の受け方）は「〜の形もあります」と言い切って紹介してよい。
- 盤上の手は「黒3」「白10」のように手順番号で呼ぶ。座標（R16 など）は読み上げない。
- 1ビート＝字幕1つ（`sub`）＋読み上げ1つ（`say`）＋盤面1枚。手順が進むたびにビートを分ける。

## 音声（VOICEVOX）のルール

- `say` は **句読点（、。）でのみ区切る。単語の間にスペースを入れない**（スペースは全部ポーズになり不自然になる）。
- 誤読しやすい語はひらがなで書く（例：三々→さんさん、一間高バサミ→いっけんたかばさみ、地→じ／じつり、手→て、右上→みぎうえ）。
- 書いたら必ず VOICEVOX の `audio_query` の `kana` で読みを確認してからビルドする。
  - 例：「はちと」→「ワチト」と誤読されるので「ハチと」と書く。「シー」→「スィー」になるので「しー」と書く。
- 声：No.7（アナウンス, speaker 30）、速度 1.1。概要欄に `音声：VOICEVOX:No.7` を必ず入れる。

## 画面

- 左：右上隅の盤面（黒＝星 Q16、白＝かかり R14 に固定）。最新の手の番号は赤。
- 右：シリーズ名／見出し／箇条書き／字幕。
- 記号：候補手は青い A・B・C、正解は青い◯、不正解は赤い✕。

## 公開

- `upload.py` は必ず **非公開（private）** でアップロードする。公開はチャンネル所有者が YouTube Studio で行う。
