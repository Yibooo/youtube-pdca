```
    O P Q R S T
 19 ＋＋＋＋＋＋
 18 ＋○●●●＋
 17 ○＋○○●＋
 16 ＋＋＋＋●＋

```

**正解：** 黒1:T19 → 白2:Q19 → 黒3:R19 → 白4:T16 → 黒5:T17

**間違い（失敗）：** 黒1:S19 → 白2:Q19

**間違い（失敗）：** 黒1:T16 → 白2:T18 → 黒3:Q19 → 白4:S19

動画 #1 では、外に抜けないように白 R16・T15 を足した形で出題する（出典の解説も、抜け出せないものとして読んでいる）。

KataGo（白 R16・T15 あり）：局所の候補では T19 が最善で、S19・T16・Q19 より 6 目以上よい。ただし T19 より手抜きの評価が約 3.5 目高かった。盤の他が空いている局面なので、大場の価値が大きく出たものと見ている。死活の結論は、手順の確認（S19 と T18 の二眼）と出典の解答による。
