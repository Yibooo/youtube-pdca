# 動画ー詰碁：準備・戦略・方針

詰碁の動画を作るための方針をまとめる。問題は Web の問題集から集めてレベル分けする。自作のプログラムで問題を探索しない。

## 3つのレベル

| レベル | 目指す棋力 | 対象 | 扱う内容 | シリーズ名（案） |
|---|---|---|---|---|
| 初級 | 10級 | ルールを理解した初心者 | 基礎基本とその派生：眼の数、急所、直三・曲三などの基本形、ナカデ | 10級をめざす詰碁 |
| 中級 | 初段 | 級位者 | 徐々に難しい問題：捨て石、ホウリコミ、ダメ詰まり、隅の特殊性 | 初段をめざす詰碁 |
| 上級 | アマ五段 | 有段者 | 手順の長い問題、複数の手筋を組み合わせる問題、コウになる問題 | 五段をめざす詰碁 |

- まず各レベル20問、計60問を用意する。
- 難易度の表記は目安とする。問題集ごとに級位の基準が違うので、同じ問題でも評価が割れることがある。
- 出典の難易度タグは Beginner／Intermediate／Advanced／Expert までで、10級・初段・五段の区別はない。古典はほぼすべて Advanced のため、中級と上級は手順の長さと、手順の順番が大切かどうかで分けた。
- 1問ずつ出典の難易度タグを記録し、実際に解いた感触で入れ替える。

| 優先 | 出典 | 内容 | 用途 |

| 2 | [Sensei's Library: Beginner Exercises](https://senseis.xmp.net/?BeginnerExercises) | 初級の問題と解答（300問以上） | 初級 |
| 3 | [Sensei's Library: Kyu Exercises](https://senseis.xmp.net/?KyuExercises) | 級位者向けの問題と解答（200問以上） | 中級 |
| 4 | [Sensei's Library: Dan Exercises](https://senseis.xmp.net/?DanExercises) | 有段者向け（約100問。古典の問題も多い） | 上級 |
| 5 | [囲碁発陽論（Igo Hatsuyo-ron, 18世紀）](https://senseis.xmp.net/?ProblemsAndExercises) | 古典。非常に難しい問題集 | 上級の一部 |

市販の問題集やアプリの問題は、著作権があるので使わない。

### 取得のルール

- `tools/fetch_sl.py` で 1 秒に 1 回ずつ取得する。サイトの `robots.txt` で禁止されたページは読まない。
- 取得した本文は選定の材料にする。解説文はそのまま写さず、自分の言葉で書き直す。

### 1問ごとに記録する項目

| 項目 | 例 |
|---|---|
| ID | `L1-01`（レベルと番号） |
| 課題 | 黒先、白死 |
| 図 | 盤面の文字図 |
| 正解手順 | 急所の初手と、相手の抵抗を含む手順 |
| よくある間違い | 間違えやすい手、相手の咎め、失敗の結果 |
| 手筋 | 急所、ナカデ、ホウリコミなど |
| 出典 | ページの URL と難易度タグ |

**正解の手と、よくある間違いの手は、必ず分けて書く。** 間違いは1問につき1〜2手とする。

## 動画の構成

定石動画の「問題 → 正解 → 不正解の手順」を引き継ぎ、詰碁向けに「考える時間」を足す。

| # | パート | 内容 |
|---|---|---|
| 1 | 問題 | 課題（黒先、白死など）を示す。サムネと同じ盤面にする |
| 2 | 考える時間 | 3秒のカウントで止める。「一度止めて考えてみてください」と促す |
| 3 | よくある間違い | 間違いの手を×で示し、相手の咎めを手順で見せる |
| 4 | 正解 | 急所の初手を◯で示し、相手の抵抗を含めて手順で見せる |
| 5 | 手筋の名前 | 今回の形と手筋の名前を言い切る |
| 6 | まとめと次回予告 | 覚えるポイントと次の問題 |

- **形式：** 1問1本の Shorts と、同じレベルの問題を10問まとめた長尺動画を基本に試す。長尺は視聴時間を積み上げる役割を持つ。
- **順番：** 初級 → 中級 → 上級の順に作らず、各レベルを少しずつ出して反応を比べる。
- **音声・言い切り：** 定石動画と同じルール（VOICEVOX、句読点のみで区切る、プロの立場で言い切る）にする。

## サムネ

**サムネ自体を詰碁の問題にする。** 見た人がその場で解きたくなる形を狙う。

| 要素 | ルール |
|---|---|
| 盤面 | 問題の図を大きく出す。隅を切り出し、石は少なめにする |
| 答え | 正解の手も×の手も載せない |
| 見出し | 短い挑戦の言葉：「黒先、白を殺せ」「1手で生きる？」「初段なら解ける？」 |
| レベル表示 | 「10級」「初段」「五段」を目立つ色の札で出す |
| 動画との一致 | サムネの盤面と動画の冒頭の盤面を同じにする |

- 「○○%が間違える」のような、データのない数字は書かない。
- 見出しは1行5文字程度を目安にする（定石動画と同じ）。

## 利用条件（未決定）

**動画を公開する前に判断が必要。** 法律の専門的な判断ではなく、規約を読んだ範囲の整理である。

| 出典 | 条件 | 収益化動画との相性 |
|---|---|---|
| 碁経衆妙など江戸期以前の古典 | 原著は著作権の保護期間を過ぎている | ◎ 問題の形はそのまま使える。解説は自分で書く |
| Sensei's Library の問題と解説 | [Open Content License](https://senseis.xmp.net/?SLCopyright)。出典表示、変更点の明示、派生物も同じ条件で無償提供、が求められる | △ 概要欄に出典の表示が必要。広告収益との両立には疑問が残る |

このチャンネルは「動画と概要欄に出典を書かない」方針なので、Sensei's Library の問題をそのまま動画にすると方針と衝突する。

**提案：** 動画にする問題は、古典と、誰でも知っている基本形（直三、曲三など）を優先する。Sensei's Library の問題は、構成の参考と検証に使う。

## 制作手順

1. レベルごとに候補を集め、`PROBLEMS_*.md` に記録する。
2. 正解と間違いの手順を出典の解答と照合し、KataGo でも確認する。
3. 台本（`videos/<id>/spec.json`）を書き、読みを `audio_query` で確認する。
4. `../scripts/make_video.py` で作り、フレームとサムネを目視で確認する。
5. `../scripts/upload.py` で非公開でアップロードする。公開はチャンネル所有者が Studio で行う。

## 検証する指標

- 詰碁と定石の Shorts で、再生数と登録者の増え方を比べる。
- レベル別に視聴維持率を比べ、次に増やすレベルを決める。
- 視聴維持率を見るには、YouTube Analytics の読み取り権限を追加する再認証が必要。
