# 方針・戦略

## 1. チャンネルのポジション

- **テーマ**: 「AI時代の定石」を、級位者〜初段前後が実戦で迷うポイント中心に解説する。
- **差別化**: 1本の動画 = 1つの定石の「基本形 → 間違えやすい手 → 咎め方 → 実戦での選び方」をセットで完結。
  プロ棋士チャンネル（柳澤理志さん等）は詰碁・手筋・名局も幅広く扱うが、こちらは**定石の体系的シリーズ**に特化し、
  プレイリストを順番に見れば「星の定石が一通り分かる」構成にする（＝視聴維持・連続再生で稼ぐ）。
- **信頼性**: 各動画の概要欄に「検証ソース（3つ以上）」を明記。AIチャンネルでも「出典つき」で信頼を取る。

※ サムネ・タイトルは「型」を参考にするだけで、画像や文言の流用はしない。

## 3. タイトル規則

テンプレート（ローテーションしてPDCAで勝ち型を残す）:

- **危険型**: 「その{手}は損！{定石名}で9割が間違える1手【囲碁定石】」
- **不安解消型**: 「{定石名}はもう怖くない！AIが選ぶシンプルな受け方」
- **最新見解型**: 「昔の{定石名}、AI時代はこう打つ【星・小ケイマかかり #n】」
- **クイズ型**: 「白の三々入り、どっちから押さえる？正解は…【囲碁定石】」

必須要素: 定石名（検索用）／間違いや問いかけ（クリック用）／シリーズ名と番号（連続再生用）。

## 4. サムネ規則

- 背景: 碁盤の局所図（隅の9×9程度を拡大）。**問題の局面**で止め、「?」マークを次の一手候補に置く。
- テキスト: 上段に赤太字（白縁取り）で問いかけ ≤ 10文字、下段に定石カテゴリ（例「星・小ケイマかかり」）。
- 悪手は赤×、正解は青◯（ただしサムネでは正解を見せない）。
- 生成: SGFから Pillow で自動描画（2026_March/scripts/generate_slides.py を改造）。A/Bの2案を作り、YouTubeの「テストと比較」で検証。

## 5. 動画の構成（8〜12分）

> 確定版のテンプレートは [VIDEO_TEMPLATE.md](./VIDEO_TEMPLATE.md)。**不正解の手を打ったときの相手の反撃手順と損失を必ず見せる。**

1. フック（0:00–0:20）: 「この局面、Aに打っていませんか？」と間違いの局面を見せる
2. 基本形（〜3:00）: 1手ずつ石を置くアニメ＋各手の意味
3. 間違えやすい手と咎め方（〜7:00）: 1〜3パターン
4. 変化・最新AI評価（〜9:00）: 小さい変化はOK（ソースで裏付けが取れる範囲）
5. まとめ・次回予告（プレイリスト内の次の定石へ誘導）

加えて、各回の「間違えやすい1手」を切り出した **Shorts（30〜60秒）** を必ず1本作り、本編へ誘導する。

## 6. 収益化戦略

- **YouTube Partner Program**: 登録者1,000人 + 長尺の総再生4,000時間（または Shorts 1,000万回/90日）。長尺は8分以上にしてミッドロール広告を入れる。
- **AI生成コンテンツのリスク対策**: YouTubeは量産・テンプレ化された動画を収益化対象外にしうる（「inauthentic content」ポリシー）。
  対策として ① 毎回の検証記録と独自の「間違えやすいポイント」分析、② 人間（自分）の最終レビュー工程、③ 投稿頻度は質を担保できる量（週3〜4本）に抑える。
- **将来の収益**: メンバーシップ（定石SGF・プリント配布）、定石まとめPDFの販売、囲碁関連アフィリエイト（書籍・碁盤）。
